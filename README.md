# Muevo Review

Páginas de revisão de vídeo da Muevo Studio.

- `index.html?j=<código>`: página que o cliente recebe para assistir e comentar.
- `painel.html`: painel interno da equipe (pede a chave da equipe).
- `config.js`: endereço do script da planilha e chave da API do Google.

Os vídeos ficam no Google Drive de vocês; comentários e lista de links ficam na planilha "Muevo Review".
